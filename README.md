# 숏쿡 컷 판정 화면

음식점 홍보 영상 서비스 숏쿡에서 생성 영상 컷이 사장님 사진과 달라졌는지 판정하던 라벨링 화면을 공개용으로 다시 만든 것입니다. 팀 시험 가게 주문의 생성 컷 9개가 들어 있습니다.

- 원본 사진(엔진 입력)과 영상의 처음·중간·끝 프레임을 나란히 보고 결함·정상·애매를 고릅니다.
- 고른 뒤에만 정답(1인 정답)과 판정 모델(Gemini, 2026-11-07 설정)의 결과가 열리고, 처음 고른 답은 바꿀 수 없습니다.
- 결함이면 종류, 크기, 프레임 3장에서도 보이는지를 함께 남깁니다. 컷 순서는 열 때마다 섞입니다.
